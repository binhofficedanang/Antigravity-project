# Walkthrough: Xây dựng công cụ WP-SEO Bot

Tôi đã hoàn thành việc lập trình các module cơ bản cho công cụ đăng bài tự động.

## Các thành phần đã hoàn thành:
- [x] Thiết lập cấu trúc dự án.
- [x] Tạo module kết nối Gemini AI (viết bài chuẩn SEO).
- [x] Tạo module kết nối WordPress API (đăng bài tự động).
- [x] File điều khiển chính (nhập từ khóa và chạy).

## Hướng dẫn sử dụng:
1. Điền thông tin vào `config.json`.
2. Cài đặt thư viện: `pip install -r requirements.txt`.
3. Chạy lệnh: `python3 main_seo.py`.

## Tiếp theo:
- Kiểm tra kết quả đăng bài thực tế.
- Tối ưu hóa việc tự động lấy ảnh minh họa (nếu cần).
