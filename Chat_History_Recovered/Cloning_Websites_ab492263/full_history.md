## 🔧 Các phương pháp clone website

### 1. **HTTrack** (Free, phổ biến nhất)
```bash
# Cài đặt trên Mac
brew install httrack

# Clone website
httrack "https://example.com" -O "/path/to/output" "+*.example.com/*"
```

### 2. **wget** (Command line đơn giản)
```bash
wget --mirror --convert-links --adjust-extension --page-requisites --no-parent https://example.com
```

### 3. **Python + BeautifulSoup/Scrapy** (Tùy chỉnh cao)
- Crawl từng trang, tải HTML, CSS, JS, images
- Phù hợp nếu cần xử lý logic phức tạp

### 4. **Browser Extension**
- **SingleFile** - Lưu toàn bộ trang thành 1 file HTML
- **Save Page WE**
